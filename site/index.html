01

对方不需要懂网络。

不用改配置，不用记地址。服务器地址、证书指纹和密钥都在 Code 里，复制粘贴就够了。

  1. 1

    发一段 Code

    在管理后台生成，可以是一次性、限时或永久的，通过你信任的渠道发给对方。

    工作区 → Code → 生成
  2. 2

    打开，粘贴，确认

    程序在本机建一张虚拟网卡，只接管组网网段的流量。默认路由和 DNS 都不动。

    10.77.1.0/24 dev tun0
  3. 3

    直接用 IP 访问

    窗口里能看到每台成员的地址。SSH、远程桌面、内部服务，用平时的工具连过去。

    ssh admin@10.77.1.3
02

隔离不靠防火墙规则。

服务端不是路由器。它没有虚拟网卡，也不向外转发，客户端手里根本没有通往服务器本机、云内网或公网的路径。规则写错会漏，不存在的路径漏不了。

每个数据包都要过这三关

  1. 必须是 IPv4否则丢弃
  2. 源 IP 必须是发送者自己的地址否则丢弃
  3. 目标必须是同一网络的在线成员否则丢弃

广播、组播、其他网络、服务器本机和公网地址都不是在线成员，自然到不了。伪造源地址的包同样过不去。

互通是双向的。同一网络的成员能访问彼此在组网接口上监听的所有端口，所以每个客户应该单独一个网络。

03

为不稳定的网络而写。

走 TCP 解决的是 UDP 被封的问题，但 TCP 本身不保证连接不断。断线检测、重连和拥塞处理都是程序自己做的。

10s一次心跳

30 秒没有响应就判定断线，休眠、换网和半开连接都能发现。

1→30s退避重连

无限重试并加入抖动，服务端重启后客户端不会同时涌入。

256有界队列

满了就丢包，不让延迟越积越高。拥塞信号交给内层 TCP，一个卡住的成员也拖不慢别人。

1小时地址保留

断线后 IP 不变。服务端重启也不丢，客户端会报回原来的地址。

每次提交都在真实虚拟网卡上跑一遍

  • 断网 60 秒，12 MB 的内层传输恢复后完整到达，校验和一致
  • 重启服务端，所有成员自动回连，IP 不变
  • 冻结一个成员并持续向它灌流量，其他成员不受影响
  • 外层链路 5% 丢包，文件传输依然完整
  • 证书被替换时连接中止，密钥不会发出
04

远程调试，对方什么都不用装。

把公钥编进 Code，对方粘贴、点确认，你就能从组网里连过去。交互 shell、执行命令、scp 和 sftp 都能用，ssh -L 可以转发到对方本机的 127.0.0.1。

# 窗口里会显示这条命令
ssh -p 2222 emil@10.77.1.3

# 传文件
scp -P 2222 app.log emil@10.77.1.3:/tmp/

# 连对方本机的调试端口
ssh -p 2222 -L 9229:127.0.0.1:9229 emil@10.77.1.3
只认一把公钥
没有密码登录，只有同一网络的成员能连到端口。
默认关闭，关了就干净
每次启动都是关的。关开关、断开组网或关闭窗口，所有会话和它们启动的进程都会结束。
建不起网卡也能连
勾选“仅 SSH，不创建网卡”后，程序自己处理组网流量，只接受 SSH 端口，不改网卡、路由和防火墙。系统网络配置被拦截时，只要还能连到服务端，就能连上去排查。

开启后，持有私钥的人能完全控制这台电脑。Windows 上远程 shell 是管理员权限，不用时请关闭。

05

服务端只有一个进程，不用写配置。

没有内核模块，也不需要 root。装好后打开网页初始化，超管创建工作区，每个团队用自己的管理员管理自己的组网。

# 安装并启动，不用写配置
systemctl enable --now varco

# 后台默认只监听本机
ssh -L 8444:127.0.0.1:8444 server

# http://127.0.0.1:8444
账号 = "root"
密码 = "admin"   # 首次登录必须修改
# 超管
创建工作区，指定网段和 owner
全局黑名单、审计、Prometheus 指标

# owner 和管理员，只管自己的工作区
生成和删除 Code，看在线成员和流量
踢人，拉黑设备或 IP
owner 还能增删管理员
06

它不做什么。

够简单才够稳定。下面这些是有意的取舍，用之前应该知道。

服务端能看到明文
TLS 在服务端终止，没有端到端加密。服务器要是你自己的；需要保密的内容请在应用层加密，比如 SSH。
全部流量经服务端中转
不做 P2P 打洞，速度取决于服务器带宽和线路。设计目标是连得上、断不了，不是跑得快。
网络替换证书时连不上
证书指纹被固定在 Code 里。如果网络在解密 TLS，连接会中止并提示原因，不会绕过。
程序没有正式代码签名
首次运行可能被 SmartScreen 或 Gatekeeper 拦截。普通模式需要提权，因为创建虚拟网卡要管理员权限。
只支持 IPv4
没有审批流、托盘常驻和开机自启。
